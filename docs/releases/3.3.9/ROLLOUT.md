# 3.3.9: один APK для всех филиалов

[Установочный APK](https://drive.google.com/file/d/1g-SqtskKFenhgprMW1A7Q3_y_HpL51-G/view):
`com.example.photovchistotu`, build `20261122`. SHA-256 скачанного файла:
`cd7ff56d4cce5ff0d25c8c8d435a9c54eed92747384211f1d6720821c61c3e15`.
Подпись v2/v3: `7d0884e53e704a683a162ca2f34c7db1e1006c07c20147d61f1892d4b3dcfca4`.

В release-клиенте нет перечня пилотных городов. Название города по-прежнему
нужно при первой регистрации для правильного чата. Тип телефона сохраняется
локально. При разрешении на сервере первый онлайн-запуск настроенного телефона
включает новые оценки в чате всего филиала, включая снимки со старого телефона.
Без разрешения филиала сам по себе выбор пицца-цеха не включает режим смен.

18.11.2026: включение подготовлено для Белозерска и Кадуя (поддержаны 3.3.8 и
3.3.9) и Кириллова (3.3.9). Вытегра исключена до активации. Для следующих
филиалов требуется только настройка на сервере и проверенная привязка чата и
оператора. Хеш APK при расширении списка не меняется.

Проверка Кириллова на изолированном AVD: установка поверх подписанной 3.3.8,
выбор основного телефона без новой регистрации, город/UUID/история/четыре файла
сохранены. Три старых фото доставлены локальному серверу по одному разу без
авторства текущей смены. После тайм-аута ADB заключительное чтение повторено
на том же AVD: все четыре исходных ID на месте, очередь пуста.
