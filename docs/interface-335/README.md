## Как читать карту

01 Обзор → 02 город, назначение и доступ к камере → 03 количество, сотрудники, основной и подтверждение → 04 один или два телефона → 05 автор кадра и очередь → 06 история, поворот, диагностика → 07 проверка в MAX → 08 карточка общего аккаунта → 09 ежедневный отчёт. Старые материалы идут после отчёта в списке фреймов.

На основном телефоне один сотрудник совмещает роли. В многочленной смене выбирают 1–2 операторов, поваров и 0–2 помощников. Отсутствие **отдельного** оператора не означает нулевое число ролей оператора. Второй телефон пицца-цеха ведёт своих 1–2 сотрудников и отдельного текущего автора. Привязка общего аккаунта для MAX от выбора фамилии оператора не меняется. Фото берёт автора на момент захвата; отсутствие старого авторства не заполняется из новой смены.

## Визуальная система

Чёрная камера `#000000`, бумага `#FFFAF4`, выбор и затвор `#F975B1`, дополнительный розовый `#FF8FBD`, подтверждённое успешное состояние `#00CAAB`. Чек и текст дублируют цвет. Камера отделена от панели управления; список авторов не требует горизонтальной прокрутки. Разовому автору соответствует «На 1 фото», основному — «Основной». Светлые формы, видимый выбор, закреплённое действие; история показывает снимок и сохранённое при съёмке имя. Ошибка, очередь и доставка не сливаются в один успех. В горизонтальной истории список находится рядом с прокручиваемыми фильтрами, а не под ними.

Основной текст около 16 sp, вспомогательный 12–14 sp, заголовки 26–30 sp; интерактивные элементы от 48 dp, основные действия 52–56 dp, затвор 64 dp. Шкала отступов 8/12/16/24 dp. Фирменный логотип извлечён из брендбука (стр. 4). Оригинальных Oddval и Helvetica с правом встраивания в предоставленных материалах не нашли. В APK **системный sans-serif** с разными начертаниями, не Oddval/Helvetica.

## Проверки и границы

- Собраны clean release и legacy debug, 43 JVM-теста прошли. Android lint без ошибок (107 предупреждений).
- Точная подписанная 3.3.4 → этот подписанный кандидат установлены через `install -r` без удаления данных между ними на одноразовом сетевом стенде. Сохранены филиал, настройки, UUID, история, идентификаторы и все четыре файла. Три прежних снимка при активном сегодняшнем поваре доставлены на loopback по одному разу, со старым ID, байты те же, без нового авторства.
- Портретный мастер/камера и горизонтальные камера/история с длинной фамилией сняты instrumentation-тестами. В последнем проверяется и фактическая ориентация Android, а не только выставленная настройка системы. Статус CI конкретной ревизии см. в Checks PR; к следующим коммитам старый зелёный результат не переносится.
- На рабочем телефоне ещё проверить физическую Bluetooth-кнопку, читаемость настоящих весов, доступное приложение для передачи диагностики, отсутствие сети и повторное открытие камеры после сна. Отдельного эксплуатационного подтверждения от APK до карточки и отчёта в этом задании нет.
