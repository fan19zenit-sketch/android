# Краткая памятка по настройке телефона

1. Установить APK на телефон.
   - старая версия: [`app-legacy-debug.apk`](d:/neiroq/android/app/build/outputs/apk/legacy/debug/app-legacy-debug.apk)
   - новая версия: [`app-clean-debug.apk`](d:/neiroq/android/app/build/outputs/apk/clean/debug/app-clean-debug.apk)
2. Открыть приложение.
3. В поле `Backend URL` ввести:
   - `http://194.55.235.241:8000`
4. В поле `Город` ввести свой город без ошибок.
5. В поле `Куда отправлять фото` выбрать:
   - `MAX`
   - или `Telegram`
6. Если это первый телефон нового города:
   - для `MAX` ввести `ID чата MAX`
   - для `Telegram` ввести `ID группы` и `ID подтемы`
7. Нажать `Сохранить`.
8. Сделать одно тестовое фото.
9. Проверить, что фото реально пришло в нужный чат.

## Пример для Шексны

- `Backend URL`: `http://194.55.235.241:8000`
- `Город`: `Шексна`
- `Куда отправлять фото`: `MAX`
- `ID чата MAX`: `-72316547549719`

## Важно

- Если город уже есть в системе, новый телефон можно просто привязать к нему.
- Если город введён с ошибкой, создастся новая запись.
- Настройка считается успешной только если тестовое фото реально пришло в чат.
